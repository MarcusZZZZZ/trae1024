# 校园瓜田 · Campus Melon

> 像素游戏风的校园趣事围观打分器：选本校、发带图的瓜、捏自己的像素小人，在广场大屏前用「夯 / 顶 / 行 / 平 / 拉」五档给瓜定位。

## 功能

- **四大校园**：江城大学、南山理工、临海学院、云顶大学，切换后各看各的瓜
- **六个板块**：全部、干饭、课程吐槽、校园景色、宿舍日常、社团活动
- **发帖带图**：标题 + 正文 + 图片，图片前端自动压缩到 900px，后端持久化
- **从夯到拉**：五档定位替代 0–10 打分，一人一票，可改票，票数实时聚合
- **像素捏人**：发型 / 发色 / 肤色 / 衣服 / 配饰自由搭配，形象会出现在现场大屏上
- **像素现场**：Canvas 低分辨率绘制夜景、人群、大屏、粒子与音效，围观人数随热度上涨
- **多用户同步**：每 5 秒轮询同步他人投票与发帖；未连上后端时自动退回本地模式

## 运行

需要 Python 3.8+，无第三方依赖。

```bash
python server.py 8123
```

打开 http://localhost:8123/

首次启动会自动建库（`melon.db`）并播种 24 条示例瓜，删除 `melon.db` 后重启即可重新播种。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/posts?campus=jc&client=xxx` | 某校园的帖子，含五档票数与「我投的档」 |
| GET | `/api/counts` | 各校园帖子数 |
| POST | `/api/posts` | 发布新瓜（图文） |
| POST | `/api/vote` | 定位，`{postId, tier, clientId}` |
| POST | `/api/join` | 凑热闹，累计热度 |
| GET | `/api/health` | 健康检查 |

## 结构

```
campus-melon.html   单页前端（原生 JS + Canvas，无框架）
server.py           标准库 HTTP 服务 + SQLite
melon.db            运行时数据库（首次启动自动生成）
```

## 说明

`clientId` 由浏览器 localStorage 生成，用于保证一人一票；清空站点数据后会视为新用户。
